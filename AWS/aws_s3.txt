Amazon S3 (Simple Storage Service)

Definition:
Amazon S3 is an object storage service provided by AWS that allows users to store, retrieve, and manage data such as files, images, videos, backups, and logs over the internet.

Use Cases:
- Storing files, images, and videos.
- Taking backups of important data.
- Hosting static websites.
- Storing application logs and reports.
- Storing data for analytics and disaster recovery.

Important S3 Concepts for Beginners

1. Bucket
Definition: A bucket is a container in Amazon S3 used to store and organize objects.
Use Cases:
- Separating data for different projects or applications.
- Storing website files and backups.
Example: my-project-backups

2. Object
Definition: An object is an individual file stored in an S3 bucket, along with its data, key, and metadata.
Use Cases:
- Storing images, documents, videos, and backup files.
Example: backup.tar.gz

3. Object Key
Definition: An object key is the unique name used to identify an object within a bucket.
Use Cases:
- Finding and accessing a particular file.
- Organizing objects using key prefixes such as logs/ or backups/.
Example: backups/backup.tar.gz

4. Versioning
Definition: S3 Versioning keeps multiple versions of an object in the same bucket when the object is uploaded or modified.
Use Cases:
- Recovering accidentally deleted files.
- Restoring an older version of a file.

5. Bucket Policy
Definition: A bucket policy is a JSON-based resource policy used to control access to an S3 bucket and its objects.
Use Cases:
- Allowing a specific IAM role to access a bucket.
- Restricting access to authorized users or accounts.

6. IAM Policy and IAM Role
Definition: An IAM policy defines permissions, while an IAM role provides temporary credentials to a trusted identity or AWS service.
Use Cases:
- Allowing an EC2 instance to upload or download files from S3.
- Giving applications secure access without storing long-term access keys.

7. Block Public Access
Definition: S3 Block Public Access provides settings that help prevent buckets and objects from being publicly accessible.
Use Cases:
- Protecting private files and backups.
- Reducing the risk of accidental public exposure.

8. Encryption
Definition: S3 encryption protects object data by encrypting it at rest.
Use Cases:
- Protecting sensitive files and backups.
- Meeting organizational security requirements.
Important types:
- SSE-S3: Encryption using Amazon S3-managed keys.
- SSE-KMS: Encryption using AWS Key Management Service keys.

9. Storage Classes
Definition: S3 storage classes provide different storage options based on access frequency, retrieval needs, and cost.
Use Cases:
- Frequently accessed files: S3 Standard.
- Infrequently accessed data: S3 Standard-IA.
- Long-term archival: S3 Glacier storage classes.

10. Lifecycle Rules
Definition: S3 Lifecycle rules automatically transition objects between storage classes or expire objects according to defined rules.
Use Cases:
- Moving old backups to cheaper storage.
- Automatically deleting temporary files after a specified period.

11. Static Website Hosting
Definition: S3 can host static website content, such as HTML, CSS, JavaScript, and images, without requiring a traditional web server.
Use Cases:
- Hosting portfolio websites.
- Hosting static landing pages and documentation.
Note: For production websites, Amazon CloudFront is often used with S3. Public access and HTTPS require appropriate configuration.

12. Replication
Definition: S3 Replication automatically copies objects from a source bucket to a destination bucket according to configured rules.
Use Cases:
- Disaster recovery.
- Maintaining copies of data in another AWS Region.
- Meeting data redundancy requirements.

13. Multipart Upload
Definition: Multipart Upload allows a large object to be uploaded in separate parts, which are then combined into one object.
Use Cases:
- Uploading large backup files.
- Improving upload reliability for large files.
