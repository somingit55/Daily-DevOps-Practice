#working on 2 branches first is main and second is dev both are on github

git branch -- #check current branch   * astrik means working branch
git switch -c dev     #create a dev branch 
git push -u origin dev   #push on Github dev branch successfully

Is command mein:
- git → Git command
- switch → branch switch karna
- -c → nayi branch create karna
- dev → branch ka naam

git push origin main   #Local main ko push karegi
git push origin dev    #Local dev ko push karegi 
git switch dev         #Local dev per switch kregi

## Now How can I merge Dev and Main Branch on Github listed below:

Step-1 Goto GitHub Repo Click on Compare & Pull Request
Step-2 Select Branches: Base->> main Compare->> dev
Step-3 Set Title Name & Description & click on Create Pull Request
Step-4 Click on Merge Pull Request & Confirm Merge Request
Step-5 Final run this below commands
git switch main
git pull origin main
