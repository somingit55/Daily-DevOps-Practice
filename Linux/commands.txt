Here the Linux Ubuntu Commands:

If you have Fresh AWS Ubuntu EC2 Virtual Server then run and understands below three commnads:

1-  sudo apt update (Package list refresh karo) 

    Repository indexes refresh hongi,Package information refresh karne ke liye
    App Store se check karna ki apps ke kaun-se naye versions available hain (Abhi Apps update ni ue hai Ok )
    /var/lib/apt/lists/   Package list yaha store hoti hai command chalane k baad

2-  apt list --upgradable (Available upgrades check karo)

    Ye available upgrades ki list dikhata hai. Output empty ho to currently listed packages mein koi upgrade available nahi hai.

3-  sudo apt upgrade  (Packages upgrade karo)

    Un apps ke available updates install karna. 
    APT changes ka summary aur confirmation maang sakta hai.-y dene par aam confirmation prompts automatically accept ho jaate hain.
