#### What is Linux?
- Linux is an open-source operating system kernel that helps you communicate directlt with the hardware.
- Linx is not an Operating System its a Kernel.
- Linux Kernel is the core of the system that talks to Hardware.
- Large collection of software is Utilities , tools, libraries , applications & more
- An operating system is created by combining a Linux Kernal with software components
- Linux = Kernel
- Ubuntu = Linux-based OS / Distribution
- Kali Linux , Fedora , RedHat = Distribution

#### What does the Linux Kernal Do?
- The Linux Kernel is responsible for managing all these interactions between your 
  software and the hardware at the most fundamental level.
- CPU Scheduling (Decides which program gets CPU time and when)
- File Management (Knows what file exist, how to list them and how to access them ).
- Memory Management (Manages how the available RAM is allocated to different programs).
- Program Execution (Load a program into memory set up what it need and runs it properly).
- Storage Management (Keeps track of how much storage is available on your HDD/SSD).
- System Coordination (Coordinates and manages all these tasks smoothly in the background).

#### What is Linux Distribution?
- A Linux Distribution is a combination of the Linux Kernel and Large colletions of Software that helps you
  operate and use a computer.

#### History of Linux
- Unix was developed at AT&T Bell Labs in 1969 by Ken Thompson, Dennis Ritchie, and their colleagues. In 1973, Unix was largely rewritten in     the  C programming language, which made it portable across different hardware platforms. Later, several Unix variants, such as BSD, Solaris, AIX, and HP-UX, emerged. Unix influenced the design of many modern operating systems, including Linux, which was created by Linus Torvalds in 1991.
